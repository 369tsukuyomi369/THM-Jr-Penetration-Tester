# THM Junior Penetration Tester

A personal walkthrough and learning journal for the [TryHackMe Jr Penetration Tester learning path](https://tryhackme.com/path/outline/jrpenetrationtester).

This repository documents my cybersecurity learning through technical explanations, command breakdowns, and practical observations. I add write-ups as I work through the path, focusing on understanding the reasoning behind each step and developing practical penetration testing skills.

## About Me

I am a Computer Science and Engineering (CSE) student, with programming experience in C++ and Java and basic Python knowledge. My interests include ethical hacking, penetration testing, Red Team operations, and bug bounty hunting.

## Learning Goals

- Build a strong foundation in penetration testing, enumeration, and web application security.
- Understand how security tools work, why they are used, and what their limitations are.
- Develop a systematic approach to investigating and validating security findings.
- Improve technical documentation and communicate practical observations clearly.

## What to Expect

As I study each topic and complete practical work, I will add:

- **Topic notes:** explanations of concepts and unfamiliar terminology.
- **Command walkthroughs:** syntax, options, arguments, and the purpose of commands I execute.
- **Lab observations:** relevant terminal output, screenshots, and analysis from my own work.
- **Lessons learned:** troubleshooting notes, limitations, common mistakes, and key takeaways.
- **References:** links to official documentation and relevant security resources.

Write-ups use the sections appropriate to the topic. Practical results reflect work I have actually performed; any hypothetical examples are clearly labeled.
